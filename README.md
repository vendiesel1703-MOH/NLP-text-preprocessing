# 🧠 NLP Text Preprocessing

This project demonstrates basic Natural Language Processing (NLP) preprocessing techniques using spaCy and NLTK.

---

## 📌 Features
- Text cleaning
- Tokenization
- Stopword removal
- Lemmatization
- Named Entity Recognition (NER)

---

## 🛠️ Libraries Used
- spaCy
- NLTK

---

## 📂 Project Structure
- `text_preprocessing_basics.ipynb` → Main notebook with implementation

---

## ▶️ How to Run
1. Open the notebook in Google Colab
2. Run all cells step by step

---

## 📊 Sample Output
Example:
Input:Apple is looking at buying U.K startup for $1 billion
Output:
Entities: Apple → ORG U.K. → GPE $1 billion → MONEY
